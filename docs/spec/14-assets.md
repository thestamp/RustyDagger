## 3. Asset Loading Pipeline

### 3.1 Original Loading

```java
FileLoader.java:
    getImage(name):
        return Toolkit.getDefaultToolkit().getImage(
            new URL(codeBase + "Images/" + name)
        )
```

Images loaded on-demand from server. `MediaTracker` used for synchronization.

### 3.2 Target Loading Pipeline

```
Phase 1: Manifest
    - Generate asset manifest (JSON) listing all files + checksums
    
Phase 2: Critical Path
    - Load Splash.jpg first (login screen)
    - Load current area images next
    
Phase 3: Background
    - Preload adjacent area images
    - Load MIDI/audio files
    
Phase 4: On-Demand
    - Monster images loaded when encounter starts
    - NPC faces loaded when entering shop
```

### 3.3 Asset Upgrade Path

| Category | Original | Upgrade Option |
|----------|----------|---------------|
| Portraits | 96×64 or 64×96 JPG | 2× or 4× upscaled PNG |
| Faces | 144×192 JPG | Higher-res replacements |
| Backgrounds | None (solid colors) | Optional parallax layers |
| Music | MIDI | Orchestrated OGG/MP3 + original MIDI |
| SFX | None | Add combat/UI sound effects |
| Fonts | System Dialog font | Custom pixel font or web font |

### 3.4 Image Naming Convention

```
Navigation: {area}{destination}.jpg (e.g., fldTown.jpg = Fields→Town)
NPC:        Faces/{NpcName}.jpg
Monster:    {Area}/{MonsterName}.jpg
Event:      Final/{EventName}.jpg
UI:         {ElementName}.{jpg|gif}
```
