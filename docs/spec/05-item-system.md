## 5. Equipment Enchantment System

### Enchant Scroll Application

Each Enchant Scroll use calls `incEnchant()` on the target equipment:

```
incEnchant():
    enchant_trait = find("Enchant") in traits
    if enchant_trait exists:
        enchant_trait.value += 1
    else:
        traits.append(new itCount("Enchant", 1))
```

### Enchantment Bonus Formulas

| Stat | Formula | Example (Enchant=10) |
|------|---------|---------------------|
| Attack | `+(enchant + 9) / 10` | +1 |
| Defend | `+(enchant + 4) / 10` | +1 |
| Skill | `+enchant` | +10 |
| Attack (FLAME, RIGHT) | `+8` (flat) | +8 |
| Defend (BLESS) | `+1` (flat) | +1 |
| Skill (LUCKY, RIGHT) | `+12` (flat) | +12 |
| Skill (GLOWS) | `+2` (flat) | +2 |

### Other Scroll Effects

**Glow Scroll:** Adds GLOWS trait → +2 skill, acts as light source  
**Bless Scroll:** Adds BLESS trait → +1 defend  
**Luck Scroll:** Adds LUCKY trait → +12 skill (RIGHT hand only)  
**Flame Scroll:** Adds FLAME trait → +8 attack (RIGHT hand only)  
**Identify Scroll:** Reveals SECRET trait, showing true item properties

### Curse Mechanics

```
isCursed() → has CURSED or CURSE trait
revealCurse():
    if has CURSED:
        remove CURSED
        add CURSE
    // Item is now visibly cursed
```

Cursed items: `stockValue = 2` (virtually worthless when identified)

## 6. Equipment Decay

### Overnight Decay

```
heroDecay(hero, rate):
    effectiveRate = (rate + hero.fightRank()) × 5
    
    for each item in hero.gear:
        item.decay(effectiveRate)
    
    for each item in hero.pack:
        item.decay(effectiveRate)
    
    // Camp gear has separate rot check
    for campItem in [Sleeping Bag, Cooking Gear, Camp Tent]:
        if hero has campItem:
            rate2 = effectiveRate / 2
            if roll(rate2) == 0:
                remove campItem
                message: "Some camping gear has rotted."
```

### Per-Item Decay

```
decay(rate):
    if roll(rate) != 0:
        return    // No decay this time
    
    // Stats degrade
    aval -= 1 ± roll(aval / 12)
    dval -= 1 ± roll(dval / 12)
    sval -= 1 ± roll(sval / 12)
    
    // 1/12 chance to lose a trait
    if roll(12) == 0 AND traits.count > 0:
        remove traits[roll(traits.count)]
    
    // Enchantment degrades
    enchant -= (enchant + 4) / 5
```

Items with the DECAY trait (e.g., Rusty Dagger) decay at an accelerated rate.

## 7. Pack Capacity

```
packMax():
    base = 60
    if has TRADER trait: base += 20
    if has MERCHANT trait: base += 20
    return base    // Max: 100

overload():
    return max(0, pack.size() - packMax())
    // Overload reduces available quests 1-for-1
```

## 8. Storage System

Heroes can store items at lodging:

```
storeMax():
    base = 100
    if has TRADER: base += 50
    if has MERCHANT: base += 100
    return base    // Max: 250
```

Storage accessed via `arStorage` screen (Transfer interface).
